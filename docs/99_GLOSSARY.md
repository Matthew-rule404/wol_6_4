# 用語集

## <span id="acme">ACME</span>

Automatic Certificate Management Environment。TLS 証明書の発行と更新を
自動化するプロトコル。

## <span id="api">API</span>

Application Programming Interface。Web UI とバックエンド間などの
機能境界を定義するインターフェース。

## <span id="csrf">CSRF</span>

Cross-Site Request Forgery。認証済みブラウザーに意図しない状態変更リクエストを
送らせる攻撃。

## <span id="csv">CSV</span>

Comma-Separated Values。カンマで列を分離した表形式テキスト。

## <span id="dns">DNS</span>

Domain Name System。ドメイン名と IP アドレスなどを対応付ける仕組み。

## <span id="icmp">ICMP</span>

Internet Control Message Protocol。PING などで到達性確認に使うプロトコル。

## <span id="l2">L2</span>

Layer 2。Ethernet の MAC アドレスとブロードキャストが扱われるリンク層。

## <span id="rfc3339">RFC 3339</span>

インターネット上の日付と時刻の表現形式。本プロジェクトでは保存時刻を UTC の
`2026-07-30T00:00:00Z` 形式に統一する。

## <span id="ssh">SSH</span>

Secure Shell。暗号化された管理接続および TCP 転送に使うプロトコル。

## <span id="tls">TLS</span>

Transport Layer Security。HTTPS 通信を暗号化し、通信相手とデータ完全性を
検証するプロトコル。

## <span id="uuid">UUID</span>

Universally Unique Identifier。Wake 操作などを一意に追跡する識別子。

## <span id="wol">WoL</span>

Wake on LAN。対象 NIC の MAC アドレスを含む Magic Packet を送信し、
対応機器の起動を要求する仕組み。
